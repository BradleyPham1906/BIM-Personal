# World-look independent check

2026-11-24

This is the second reading that `docs/research/research-protocol.md` (part 9, "An independent check") asks for, of
the three side notes `weather-sky.md` (WS), `rendering-efficiency.md` (RE) and `assets-audio.md` (AS). For each fact
that the code or the owner's decisions will rely on, the primary source was fetched again on 2026-11-24 through this
environment's proxy (not the other agents' copies), converted to plain text (HTML stripped, PDFs through
`pdftotext`) and searched for the passage; downloads were kept as text in the session scratchpad and never run. The
repository claims were checked against the files themselves: the vendored three.js bundle by its esbuild export map
(`,Name:()=>` entries), and the engine sources by line. Three experiments were re-run here (Node 22 and Chromium
through Playwright): the weather blend, the instancing memory at 100,000 trees, and the Web Audio distance gain. No
call was made to Open-Meteo's API (the shared address is rate-limited) or to MET Norway's API (its terms forbid
anonymous or invented identification); api.weather.gov was asked once for its CORS header. Verdicts: CONFIRMED,
NOT CONFIRMED (with what the source says) or COULD NOT READ (with why).

## What failed, and what the notes must change

1. **C8, MET Norway from the browser (weather-sky.md 4.1, 4.6, 5, 11 and 12).** The terms allow a browser only
   "simple cross-origin" requests from "low-volume websites", say preflights and custom headers are "explicitly not
   supported", say heavy traffic must go through a caching proxy, and say the CORS conditions are "still under
   review". The note must drop the advice to send `If-Modified-Since` from script (a non-safelisted header forces a
   preflight); let the browser's own HTTP cache revalidate, and honour `Expires` by not asking again before it. It
   should state that MET Norway is usable keylessly from the app only while traffic is low, that a proxy is the
   terms' answer for anything more, and that the project's rule is to name, not proxy, so the fallback rests on the
   owner's decision. It should also record the terms' new "Use of AI agents" clause: the terms "must be read,
   understood and accepted by a human in authority", so the owner, not an agent, accepts them before the app uses
   the service.
2. **C5, Open-Meteo's per-model metadata.** Not re-read here (rate limit). The levels stay as measured, but the
   note's "1 to 6 hours" should say "for the models named" (C4: ItaliaMeteo updates every 12 hours).
3. **Limits to add, not failures.** RainViewer's own "Terms of Use" paragraph says "personal or educational use",
   narrower than its FAQ (C11); quote both. Quaternius gives only "a portion" of each CC0 kit for free, the rest to
   Patreon supporters (C16, C17); the plan should name the free files it will pin. Freesound still carries legacy
   Sampling+ sounds (C23); the CC0-only filter covers them, but the note should name them. The instancing
   results file is older than its page (C39); rerun it and commit the new numbers, or state the difference.
